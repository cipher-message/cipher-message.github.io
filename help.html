Help & FAQ

Quick answers about Cipher Message.

What is Cipher Message?

Cipher Message is a school messenger with direct messages, group chats, voice and video calls, file sharing and customisable themes.

Is Cipher Message free?

Yes. You can create an account and use Cipher Message for free.

How do I create an account?

Open the app, press Sign up, and follow the steps. You can then add friends and start your first channel.

Can I use Cipher on my phone?

Yes. Open the site in your phone's browser. On iPhone, tap Share and then Add to Home Screen. On Android, use the browser menu and choose Install app or Add to Home screen. Cipher then opens like a normal app with its own icon.

Is there a Windows app?

Yes. A Windows version is available from the site on Windows computers. It can run in the background so you still get message and call notifications.

Are my messages private?

Cipher is designed with privacy and security in mind, including encryption and server-side access rules. See the Privacy page for what is stored and how it is used.

How do I report a problem or a person?

Use the report and block options inside the app. They are on each chat and profile.

I forgot my password. What do I do?

Use the password reset option on the sign-in screen. A reset link is sent to your account email.
